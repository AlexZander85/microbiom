# Синтез предложений и статус сравнения

**Дата:** 14.10.2026. **Статус:** предварительный синтез доступных материалов.

В репозитории нет отдельного «Проекта» и двух агентских ревью. Не было прочитано ни одного такого ревью. Нельзя приписывать отсутствующим агентам идеи или утверждать, что сравнение завершено. Независимая оценка зафиксирована отдельно в `01-independent-review.md` до синтеза.

## Матрица решений по доступному ТЗ

| Предложение пользователя | Независимая оценка | Решение в спецификации |
|---|---|---|
| Человек → орган → микроб → механизм | Основа учебного маршрута | Принято; уровни связать навигацией и картой масштаба |
| Все группы, все места обитания | Не обещать полноту по каждому виду | Репрезентативный атлас + план расширения; низкая биомасса отдельно |
| Добрые и злые микробы | Научно вводит в заблуждение | Функции, штаммы и контекст вместо моральных цветов |
| 3D без библиотек | Модули дают проекцию объёмной геометрии | Ортографический 3D в Canvas; WebGL для полей; mesh-движок не притворяться готовым |
| Path2D вместо SVG DOM | Согласен | Прямой адаптер; кэш геометрии и растровый LOD на общем плане |
| Четыре тона, цвет, гало | Усилят читаемость | Цвета вида постоянны, цвет не означает патогенность |
| Полные сложные клеточные устройства | Только реальные для данного таксона признаки | Базовая схема + trait-based расширение после научного ревью |
| Пять ярусов ткани | Не универсальны | Пять в дистальной толстой кишке, иные наборы в остальных биотопах |
| Сплошная EPS-плёнка | Не модель нормальной кишки | Локальные сообщества; зрелую биоплёнку отдельно моделировать на зубе |
| BAM как минное поле | Гипотеза/экспериментальная модель | Только с маркировкой уровня доказательств |
| Плазмида переплывает целиком | Не соответствует обычной конъюгации | Показать цепь ДНК и достройку двух копий |
| T6SS-пружина | Образ полезен, структура белковая | Схема с оговоркой, не атрибут всех микробов |
| Бутират, O₂, антибиотик в шейдере | Согласен при едином источнике данных | Поля из модели, условные единицы; не физически достоверная жидкость |
| «Реальные биохимические показатели» | Нет данных калибровки | Реальные **значения модели**, не реальные анализы организма |
| Автотур через 1,4 секунды | Мешает чтению без согласия | Только opt-in; пауза/диалог/чтение/действие прерывают |
| 60 FPS на любом устройстве | Нельзя гарантировать | Измеряемая цель на согласованной матрице устройств + fallback |
| Без сборки и сервера | ES modules требуют HTTP в обычной поставке | Второй файл `standalone.html`, открывается по file:// без загрузок |

## Как завершить сравнение после получения файлов
1. Получить оригинальный проект, ревью A и B, сохранить авторство/названия и дату.
2. Не изменять независимое ревью задним числом; дополнения — отдельным документом.
3. Разбить предложения на научные, педагогические, визуальные и инженерные требования.
4. Для каждой идеи зафиксировать автора, совпадения, конфликт, источник доказательства, стоимость, решение и ID требования.
5. Проверить, не потеряны ли сильные идеи исходного проекта, добавить delta к спецификации и тестам.
6. Составить журнал разногласий: эстетическое предпочтение не может отменять научную оговорку.

Пока эта процедура **ожидает материалов**, а спецификация ниже не называется согласованным синтезом двух отсутствующих ревью.
