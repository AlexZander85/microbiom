# 0.11 · Первый вычисляемый путь кишечник → мозг

15.10.2026. Продолжение [поэтапного контракта](16-connected-physiology-plan.md). **Один нутриентный афферентный путь, не полная ось и не модель влияния микробиома на настроение.**

## Выбранный механизм и основания

Глюкоза в кишечном просвете → сенсорный энтероэндокринный эпителий (neuropod-функция) → локальная глутаматная передача → вагальный афферент → стволовая мишень NTS (ядро одиночного пути).

- Kaelberer et al., 2018, *A gut-brain neural circuit for nutrient sensory transduction*, Science, [10.1126/science.aat5236](https://doi.org/10.1126/science.aat5236). Экспериментальная основа сенсорной эпителиальной клетки, вагального нейрона и глутаматной передачи, преимущественно мышиная модель. Эта работа **не является источником численных коэффициентов приложения**, не доказывает клинический эффект микробиома и не служит калибровкой NTS.
- Barton et al., 2023, *Enteroendocrine cell regulation of the gut-brain axis*, [10.3389/fnins.2023.1272955](https://doi.org/10.3389/fnins.2023.1272955), разделы 2.1–2.2. Обзор различает синаптическую/паракринную передачу, обсуждает реакцию на глюкозу и глутаматные рецепторы; отмечает сравнительно ограниченный объём работ о neuropod-клетках. Не переносить этот механизм на все энтероэндокринные клетки и все сигналы кишечника.

Внутренние кальциевые токи, конкретные популяции/электрофизиология NTS и SGLT1 здесь не реконструируются. NTS — **сокращённая вычисляемая мишень**, получающая задержанный афферентный вход. Показатель является нормированной вызванной активностью, не частотой спайков, не c-Fos, не настроением и не диагнозом. Рабочая модель ещё не прошла независимую научную приёмку.

## Пользовательский опыт

Толстая кишка → мини-исследование **«Кишечник сообщает — мозг получает сигнал»**. Это точка входа в лабораторию, а не утверждение, что NTS находится в кишечнике; сенсор и транспорт относятся к условному кишечному резерву. В 3D показана схема четырёх звеньев, не анатомическая реконструкция.

A и B получают по 1 ммоль **добавленной глюкозы** на шагах 10 и 600. Начальный добавленный материал равен нулю, базальная гликемия не моделируется.

| Вариант B | Вмешательство | Что различает |
|---|---|---|
| Синаптический блок | Передача от глутаматного выхода к афференту выключена до шага 450 | Высвобождение сигнала и его приём не одно и то же |
| Вагальный блок | Новые сигналы не входят в линию передачи до шага 450 | Местное возбуждение может сохраниться без доставки в NTS |
| Сразу в кровь | Те же 1+1 ммоль вводятся в системный пул | Количество в крови не заменяет активацию выбранного кишечного сенсора |
| Без нарушения | Нет команд | B полностью совпадает с A |

В первых двух вариантах на шаге 450 связь восстанавливается, но уже прошедшая история не стирается. Второй импульс снова вызывает ответ. Сигналы, уже вошедшие в линию, не исчезают мгновенно при блокаде; остаточная активность затухает. Это учебные контроли, **не предлагаемые вмешательства человеку**.

На шаге 300 в стандартном опыте синаптического блока: добавленная глюкоза крови A/B одинакова, около 1.0296 мМ; NTS A около 0.2209, B = 0. После восстановления и второго импульса на шаге 800 оба ответа около 0.4158. Нулевой вызванный ответ не означает отсутствие всей активности мозга. При прямом вводе в кровь сенсор этого кишечного пути не возбуждается; реальные центральные/периферические сенсоры глюкозы и другие пути **не моделируются**.

## Физически определённый материал, но не физиологическая калибровка

`src/physiology/gut-brain.js`, отдельный сценарий `gutbrain` и версия `local-0.11.0`.

Это **новое состояние глюкозы**, а не переименование D/R/Q/M выпуска 0.10. Один `LocalSimulation` хранит все материальные отсеки, нервные состояния и очередь задержки; replay восстанавливает их вместе. Прежние модели и контрольные суммы не модернизированы задним числом.

Единицы количества — ммоль глюкозы; концентрация = количество / объём в литрах, результат — мМ. Время — учебные единицы, **не секунды/часы пищеварения человека или мыши**. Все нижеприведённые параметры выбраны для объяснения, а не взяты из измерений.

| Параметр | Значение и единица | Статус |
|---|---:|---|
| Объём кишечного пула | 0.1 л | Учебный |
| Портальный объём | 0.02 л | Учебный |
| Печёночный объём | 0.05 л | Учебный |
| Системный объём | 0.3 л | Учебный |
| Выход из желудочного резерва | 0.12 / уч. время | Учебный |
| Всасывание / кишечный вынос | 0.18 / 0.025 за уч. время | Учебные |
| Портальный → печёночный | 0.3 / уч. время | Учебный |
| Печёночный → кровь / использование | 0.18 / 0.08 за уч. время | Учебные |
| Использование из крови | 0.04 / уч. время | Учебный |
| Полунасыщение сенсора | 2 мМ | Учебное, не измеренный Km SGLT1 |
| Постоянные отклика: сенсор / глутаматный выход / NTS | 0.6 / 0.3 / 1.2 уч. времени | Учебные |
| Линия задержки | 10 шагов по 0.1 уч. времени | Наглядная задержка, не физиологическая скорость нерва |

Объёмы описывают искусственную систему: не называются человеческой или мышиной анатомией. Для глюкозы не рассчитывается связывание с белками, а также инсулин, эндогенная продукция, обратный транспорт, осмотические эффекты или насыщаемый клиренс. Печёночное использование — учтённый терминальный резерв эквивалентов поступившей глюкозы, не запас неизменённой глюкозы внутри печени. Вынос из просвета также терминальный; почечная глюкозурия не моделируется.

Материальный маршрут: желудочный резерв → кишечный → портальный → печёночный → кровь. Из кишечного пула параллельно идёт вынос; из печени и крови — использование. Потоки исходят из снимка начала шага. Для общего коэффициента k из X уходит `X · (1 − exp(−k·dt))`; конкурирующие выходы делят это количество пропорционально своим коэффициентам.

Баланс: `внешние входы = запасы желудочного, кишечного, портального, печёночного и кровяного пулов + использованные эквиваленты + кишечный вынос`. Он проверяется отдельно **в ммоль**, не смешивается с условными у.е. C ранних лабораторий.

## Нервная часть — передача информации

Сенсорный вход `C / (2 + C)`, где C — кишечная глюкоза в мМ. Сенсор, нормированный глутаматный выход и NTS — низкочастотные звенья с обновлением `x += (target − x) · (1 − exp(−dt/τ))`. Афферент получает глутаматный вход только при включённой синаптической передаче. Очередь задержки принимает афферентный сигнал при включённой вагальной передаче, затем подаёт его на NTS.

Глутаматный выход — **нормированная активность высвобождения**, не концентрация/масса глутамата; обмен самого нейромедиатора не рассчитывается. По нерву не списывается и не переносится глюкоза. Нет переноса кишечного серотонина через ГЭБ. Гуморальный путь через ГЭБ не выбран и не изображён работающим.

## Проверки и пределы готовности

8 новых тестов биологии: расхождение крови/ответа при блоках, восстановление, прямой ввод, идентичный контроль, неотрицательность/материальный баланс/рёбра, задержка и сохранение уже отправленных сигналов, все варианты replay, неизменность старых версий. Прежняя проверка учебных записей автоматически включает новый сценарий. Браузер проверяет четыре варианта, графики, перемотку, загрузку, отказ неверного плана, ветку, 390px, восстановление WebGL и `file://` без HTTP.

Полная ось двунаправленна и содержит гораздо больше путей. **Здесь не реализованы**: микробный источник сигнала, его связь с ресурсной конкуренцией/муцином, гуморальные и иммунные пути к мозгу, ГЭБ, обратная эфферентная регуляция кишечника и поведенческий результат. Дальнейшее расширение требует отдельного причинного контракта и источников, а не подключения состава микробиома к универсальному индикатору.
