# Матрица реализации — 0.6 / Discovery Edition

**Аудит: 15.10.2026 (Asia/Yekaterinburg). Полная спецификация НЕ реализована.**

Основание: актуальные исходники основного приложения, [PROJECT_SPEC.md](PROJECT_SPEC.md), unit- и браузерные проверки. Функции `renderer-lab.html` не засчитываются основной сцене, исторический `classic.html` — тоже. Процент готовности не приводится: пункты несопоставимы по объёму, а научная валидация не заменяется количеством написанных функций.

**Готово** = работает указанная ограниченная функция; не означает научную приёмку всего раздела. **Частично** = есть рабочая основа, но явно перечислен остаток. **Не сделано** = требуемого процесса/приёмки нет, даже если есть поясняющий текст или анимация.

### Замеры скорости — не взаимозаменяемые сцены

0.5 локальная лаборатория: около **11,3 FPS**, ~6,4 тыс. треугольников, десятки агентов, Chromium/SwiftShader. Это не тест плотного обзора и не доказательство ускорения прежнего renderer. Плотный обзор 0.5 дал **5,49 FPS** (~49 тыс. треугольников) на SwiftShader. Исторические JSON сохранены.

Финальная 0.4: **5,59 FPS**, median **183,2 мс**, p95 **200 мс**, около **49 тысяч треугольников**, 26 draw calls; Chromium/SwiftShader, 1440×1000, короткий активный маршрут. Предварительная 0.4 до добавления дешёвого отсева луча по границе экземпляра дала **4,63 FPS** ([сохранённый результат](benchmarks/structure-living-before-bounds.json)); историческая 0.3 — **5,40 FPS**. Это не контролируемая аппаратная A/B-серия: маршрут живой, количество видимых объектов немного различается, среда измерения шумная. Нельзя из этих трёх чисел выводить гарантированный прирост или скорость на Intel/AMD GPU.

Это техническая приёмка ограниченных маршрутов Chromium/SwiftShader, **не доказательство научной полноты, понятности детям или достижения 60 FPS**.

## Следующий содержательный этап

Согласованный обмен между локальным участком и агрегированной моделью (веса агентов, ресурсы, барьер, отсутствие двойного учёта); расширение и внешняя проверка штаммовых/иммунных механизмов; химия pH/буфера; аппаратный профиль на согласованном встроенном GPU. Уже реализованные локальные процессы не заменяют эти остающиеся этапы.
