# Проверки v0.2 / WebGL2 Edition

Дата: **15.10.2026**. Проверяется новая главная страница, не classic. Результаты v0.1 из `04-science-and-validation.md` к новому движку не относятся.

## Среда

- Node 22.22.3; Python — только статический сервер/упаковка.
- Playwright + npm-пакет `@sparticuz/chromium`, Linux sandbox, Chromium WebGL2/ANGLE/SwiftShader (software).
- Статический HTTP на порту 8000. Браузерные зависимости необязательны и не входят в runtime.
- Запуск здесь: `LD_LIBRARY_PATH=/tmp/al2023/lib node tests/browser-webgl2.mjs`.
- Тесты не отключают web security. Файл проверяется обычным `file://`, не через `--allow-file-access-from-files`.

## Автоматические проверки

**22 unit-теста — PASS** (`node --test tests/*.test.js`):

- Детерминированность seed, reset и последовательности вмешательств.
- Все биотопы/возмущения: положительность, конечность, границы.
- Избирательность условного антибиотика и уже имеющаяся устойчивость.
- Бутират в парном опыте, оральное закисление, отсутствие мгновенного разрушения барьера от паузы питания.
- Корректность ссылок данных.
- Сохранённые geometry/spring-контракты anatomy v0.1.
- Перспективная проекция и луч, quaternion-ориентация, mesh index bounds и конечные координаты.
- **Направление нормалей** оболочки: отдельная регрессия исправленной ошибки frame basis.
- Depth-sensitive ray/sphere и формат instance-буфера.
- Детерминированные массивы представителей, изменение плотности без изменения biological snapshot, sparse-профиль.
- Пространственная локальная доступность пищи.

**Сквозной браузерный маршрут — PASS**, без необработанных JS-ошибок:

1. Реальный контекст WebGL2 и перехваченные native `drawElementsInstanced`, центральная сцена и органное приближение.
2. Профили 1800/3600/7000; сравнение snapshot до/после изменения плотности на паузе.
3. Проекция точки конкретного экземпляра → реальный click в canvas → ray picking; follow, отдельный инспектор, пробел, возврат.
4. Предсказание → локальная клетчатка → рост модельного субстрата относительно контроля; диалог A/B, журнал и JSON download.
5. Все девять биотопов, в лёгких 240 представителей вместо тысяч.
6. Поиск/фильтр атласа, три отдельные WebGL2-схемы.
7. `WEBGL_lose_context`: потеря и восстановление контекста/ресурсов.
8. 390×844 CSS viewport: отсутствие горизонтального overflow страницы; диалог открывается/закрывается. Это не тест реального touch/GPU телефона.
9. Автономный HTML по `file://`, HTTP-запросы заблокированы, запросов нет; preference reduced-motion учтён.
10. Принудительное отсутствие WebGL2: явное объяснение, `available=false`, не необработанное исключение.

Дополнительно `tests/journey-webgl2.mjs`: путь в микросреду и обратно с обычной анимацией (не reduced-motion) — **PASS**. Повторная упаковка standalone даёт идентичный SHA256.

Снимки экрана — в `docs/screenshots/`. Это изображения реального браузера, не сгенерированные макеты.

## Производительность — ограниченная, не целевая приёмка

`tests/performance.mjs`, 1280×900, default 3600 представителей, reduced-motion, ~8 секунд на сцену после прогрева; камера микросцены depth 2.55. Renderer:

`ANGLE (Google, Vulkan 1.3.0 (SwiftShader Device (Subzero) (0x0000C0DE)), SwiftShader driver)`.

| Сцена | Среднее FPS | Median кадра | p95 кадра | Draw calls | Треугольники/кадр | Нарисованные instances |
|---|---:|---:|---:|---:|---:|---:|
| Человек | 20.62 | 50 ms | 50.1 ms | 15 | 28 916 | 186 |
| Микросреда | 3.12 | 316.7 ms | 350 ms | 15 | 442 438 | 2 939 |

Instances включают ткань/частицы; часть представителей вне frustum не рисуется. Числа — конкретный короткий software-run, зависят от камеры, размера canvas и сцены. Низкое FPS микросцены — **известный незакрытый недостаток**, а не «проверка 60 FPS пройдена». Нужны реальный GPU, длинные прогоны переходов/разбора/опытов, мобильные профили и дальнейшая оптимизация. Нельзя переносить сюда прежние ~50–60 FPS Canvas/WebGL1.

## Чего эти тесты не подтверждают

- Научную калибровку, количественный прогноз здоровья, клиническую правильность.
- Полное соответствие анатомии, реалистичность каждой оболочки/органеллы.
- Правильность всей иммунологии/генетики: большая часть этих механизмов ещё не моделируется.
- Экспертную доступность, детскую понятность, usability на реальном телефоне.
- Полноценный лизогенный цикл, local HGT, lineage/replay, точную окклюзию при выборе.
- Завершение всех требований долгосрочной спецификации; фактическая матрица — §11 `PROJECT_SPEC.md`.
